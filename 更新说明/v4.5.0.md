## AI 好友 v4.5.0

### ✨ 新功能：等你说完再回

真人聊天经常一句话拆成好几条发。以前它只等 2.5 秒，你打下一条稍微慢一点，它就先回了前半句。现在：

| 情况 | 它怎么做 |
| --- | --- |
| 你发完最后一条 | 等 3 秒没新消息才开始回（「设置 → QQ」可改） |
| 话像没说完：「我跟你说」「对了」「然后」、逗号结尾 | 多等一倍时间 |
| 只发了一张图（多半还要配字） | 多等一半时间 |
| QQ 上显示你「正在输入…」 | 接着等，你停下或发出来再说 |
| 它已经在想 / 正准备发，你又发了一条 | 这版不发了，把你所有的话连起来重新想（一轮最多重想 2 次，不会一直不回） |
| 你一直在发 | 从第一条算起最多等 20 秒（可改），到点就回 |

- 几条消息会作为一段话交给模型，它会先弄懂你整体想说什么，再整体回应
- 网页聊天也一样：输入框里还有字（你还在打）时会接着等
- 「正在输入」靠 NapCat 上报 `input_status` 事件，NapCat 不报也没关系，其余几条照样生效

### 🛠 其他
