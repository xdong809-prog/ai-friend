## AI 好友 v4.3.0

这一版是看了真实聊天记录之后做的调整：修掉几处实际用起来才会碰到的问题，再加上「记着你的安排主动关心」。

### ✨ 新功能

**记着你的安排，主动关心**
- 你说过「周五面试」，它会在前一天晚上给你打打气，当天晚上（或第二天）问问结果怎么样了
- 每个安排最多各发一次；正聊着、深夜都不会打扰；问过之后聊天时也不会再追问
- 默认开启，在「设置 → 像真人」里可以关掉

**有作息**
- 工作日和周末过得不一样
- 深夜会有点困，回得慢一点、短一点

### 🔧 根据真实聊天做的修复

- **不再一直讲自己的事**：它说过自己在干嘛以后，不会每条都绕回去讲，聊天的重心放在你身上
- **表情包看图更稳**：QQ 图片链接下载失败时，改用 NapCat 存在本机的那份；看图模型输出被截断时也能读出描述，旧版存坏的记录会自动修正
- **备用模型更聪明**：「备用模型」没设，或者和聊天模型是同一个时，出错会自动换另一个能用的模型

### 🛠 其他

- 黑窗口里的内容同时存到 `data/logs/server.log`，方便排查问题（密钥自动打码）
- 新增 `运行测试.bat`，双击就能在本机跑全部 78 项测试；上传到 GitHub 后也会自动在 Windows 和 Linux 上跑一遍
- `上传到GitHub.bat` 现在双击就能把改动提交并上传

### 🔄 从 v4.2 升级

把压缩包里的文件覆盖到原来的文件夹就行，`config.json` 和 `data/` 不在压缩包里，不会被覆盖。覆盖后关掉黑窗口，重新打开。
