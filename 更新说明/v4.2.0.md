## AI 好友 v4.2.0

一个跑在你自己电脑上的 AI 好友：可以在网页里聊，也能接进 QQ。它记得住你、接得住上下文、说话像真人；聊天记录和记忆只存在你自己的电脑上。

### ✨ 亮点

**更像真人**
- 每次回复前先在心里想一句（不会发出去），带着心情回话，心情会延续到下一轮
- 自动去掉「作为一个 AI」「希望对你有帮助」这类客服腔；被吐槽时会回嘴、撒娇，不会客服式认错
- 长段落拆成几条短消息，按字数「打字」，QQ 上会显示「对方正在输入…」
- 知道现在几点、隔了多久没聊；戳它它会回应，有时还会戳回去

**记得住、接得上**
- 最近的聊天原文完整带上，更早的自动压缩成摘要，中间不会断片
- 大模型帮它整理关于你的记忆：名字、城市、喜好、经历……新说法会覆盖旧的
- 你说「周五面试」，它会换算成具体日期，到时候问你结果
- 连发几条会当成一段话来回；在 QQ 里「回复」某条消息时，它能看到你引用的原文

**看图、表情包、联网**
- 看得懂你发的图片和表情包（同一张图只识别一次）
- 有自己的表情包库，会按心情挑一张发给你；你发给它的表情包它会收藏起来学着用
- 认得全部 329 个 QQ 表情，也知道 [微笑] 多半是在阴阳怪气
- 问天气、新闻、比分时会先联网查，查不到就直说

**多模型、多风格**
- 支持 DeepSeek、Kimi、通义千问、智谱、豆包、硅基流动、OpenRouter、OpenAI、Claude、Gemini、MiniMax、本机 Ollama，以及任何兼容 OpenAI 接口的服务
- 网页上一键切换；在 QQ 给它发「/模型」也能换
- 聊天、整理记忆、看图可以分别用不同的模型；聊天模型出错时自动换成备用模型
- 12 种性格：温柔、傲娇、沙雕、高冷、甜妹、霸总、知心、二次元，以及新增的**英式冷幽默、美式损友、脱口秀吐槽、海归中英夹杂**；说话语言可选中文、中英夹杂或英文

**省心、安全**
- 零依赖，装好 Node.js 双击就能跑；支持开机后台自启
- QQ 掉线时电脑右下角弹提醒（也可以推送到手机）
- 只在本机访问，会拒绝其他网站发来的请求；私聊默认只理主人；日志里的密钥自动打码

### 🚀 快速开始

1. 安装 [Node.js](https://nodejs.org)（18 或更高，选 LTS 版）
2. 下载下面的 **ai-friend-v4.2.0.zip**，解压到任意文件夹
3. 双击 `启动.bat`，浏览器会自动打开聊天页
4. 在「模型」页添加一个大模型并填 API Key，点「测试」确认能用
5. 想接入 QQ：准备一个 QQ **小号**和 [NapCat](https://github.com/NapNeko/NapCatQQ)，按网页「状态」页的步骤配置，然后在「设置」里填上你的主人 QQ 号

详细说明见仓库里的 [README](../../blob/main/README.md)。

### 🔄 从旧版（v3.x）升级

双击 `导入旧项目数据.bat`，可以把旧版的 API Key、主人 QQ、NapCat 设置、聊天记录和记忆导进来，旧项目本身不会被修改。新旧版用同一个端口（8787），不能同时开。

### ⚠️ 注意

- NapCat 不是腾讯官方接口，有账号风控风险，请用小号
- OpenAI、Claude、Gemini、OpenRouter 需要电脑能访问国外网络
- 各家模型名更新很快，添加模型时请点「获取模型列表」，以服务商实际提供的为准
- `config.json` 里有你的 API Key，不要发给别人；它和 `data/` 文件夹已经被 `.gitignore` 排除
- AI 的回复可能出错，不要当成事实或专业建议；聊天内容会发给你配置的大模型服务商
