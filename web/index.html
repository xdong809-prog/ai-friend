          怎么接入 QQ

          1. 准备一个 QQ 小号当机器人（第三方协议有风控风险，别用大号）。
          2. 启动 NapCat 并扫码登录小号，打开它的 WebUI（通常是 http://127.0.0.1:6099/webui）。
          3. 在「网络配置」里新建 HTTP 服务器：端口 3000。
          4. 再新建 HTTP 客户端（上报）：地址 http://127.0.0.1:8787/onebot，消息格式选 array。
          5. 两处的 Token 可以留空；要填就填同一个，并在本页「设置 → QQ → NapCat 连接」里填上。
          6. 在「设置」里填上你的主人 QQ 号，保存。用大号私聊小号试试。
