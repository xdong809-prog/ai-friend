          最近的总结

            把你和某个人的聊天记录导进来，新建一个扮演这个人的 AI：它会学他/她的说话方式，记得你们聊过的事。聊天时它会参考以前的聊天来回，但不会照搬原话。角色只在网页上聊，QQ 上还是原来的好友。

            导入聊天记录

            QQ 导出的 .txt、微信导出的 .txt / .csv

            QQ：电脑版「消息管理器」里右键聊天对象 → 导出消息记录 → 选 .txt。微信：用留痕（WeChatMsg）等工具导出成 txt 或 csv。

            导入时会把聊天记录分段发给「整理记忆」用的那个大模型，让它整理回忆和说话方式（聊得越多越久，大概要几十秒到几分钟）。聊天记录只存在这台电脑。

                怎么接入 QQ

                1. 准备一个 QQ 小号当机器人（第三方协议有风控风险，别用大号）。
                2. 启动 NapCat 并扫码登录小号，打开它的 WebUI（通常是 http://127.0.0.1:6099/webui）。
                3. 在「网络配置」里新建 HTTP 服务器：端口 3000。
                4. 再新建 HTTP 客户端（上报）：地址 http://127.0.0.1:8787/onebot，消息格式选 array。
                5. 两处的 Token 可以留空；要填就填同一个，并在本页「设置 → QQ → NapCat 连接」里填上。
                6. 在「设置」里填上你的主人 QQ 号，保存。用大号私聊小号试试。
